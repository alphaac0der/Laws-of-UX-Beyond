<Section id="plain" title="In plain words">
<Analogy>
Working memory is like a small kitchen counter. You can only put a few ingredients on it while you cook. Add too many and things start falling off.

Long-term memory is the pantry: huge, but it takes time to fetch things from it.
</Analogy>

Working memory is where we **hold and juggle** information right now, like a code we just read, a price we want to compare, or the step we were on. It’s small, it fades within seconds, and it’s easily disrupted.
</Section>

<Section id="why" title="Why it happens">
Psychologists Alan Baddeley and Graham Hitch described working memory as a set of small mental workspaces: one for sounds and words, one for images and positions, and a “central executive” that directs attention between them.

It can only hold a few chunks at a time, and things disappear in **about 20 seconds** unless we keep repeating them. Switching screens, reading a pop-up or getting interrupted can wipe it completely. That’s why people forget the code they were copying the moment a notification appears.

<div class="callout">
  <strong>Recognition beats recall.</strong> It’s far easier to <em>recognize</em> something you can see, like a menu item, a recent search or a product thumbnail, than to <em>recall</em> it from memory. Show, don’t ask people to remember.
</div>
</Section>

<Section id="examples" title="Real-world examples">
<ul class="examples">
  <li><strong>Amazon’s “Recently viewed”</strong><p>Items you looked at stay visible, so you don’t have to remember what you saw ten minutes ago.</p></li>
  <li><strong>SMS code autofill</strong><p>iOS and Android offer to fill in one-time codes from messages, so nobody has to memorize six digits.</p></li>
  <li><strong>Breadcrumbs and progress steps</strong><p>They show where you are and how you got there, so you don’t have to keep track yourself.</p></li>
  <li><strong>Google Search suggestions</strong><p>Past searches and suggestions let you recognize what you want instead of retyping it from memory.</p></li>
</ul>
</Section>

<Section id="apply" title="How to apply it">
<Checklist>
- **Keep relevant information visible** across steps, like order summaries, selected options and context.
- **Use side-by-side comparisons** instead of making people flip between pages.
- **Offer recognition over recall** with recent items, suggestions, autocomplete and history.
- **Avoid interruptions** in the middle of tasks that need concentration.
- **Support copy, paste and autofill** for codes, numbers and addresses.
</Checklist>
</Section>
